# Positioning Decay Fixture v1

This fixture tests whether a strategy skill can turn a contradictory evidence pack into a defensible positioning decision.

## Task

Using only [`input.md`](input.md), determine whether HelioDesk should preserve, refresh, or replace its current positioning. Produce the most decision-useful artifact the skill is designed to create.

Constraints:

- Do not invent customer research, market facts, financial data, or proof.
- Label inference and unresolved questions.
- Make the recommended decision, trade-offs, near-term tests, and ownership visible.
- Treat the 90-day constraint and installed-customer base as real constraints.
- Do not read [`evaluator-reference.md`](evaluator-reference.md) while generating an output.

## Why this fixture is difficult

- The company has a real product advantage, but it is not the advantage named in its positioning.
- The market is moving toward a competitor's language, so copying the market leader would create a second differentiation problem.
- Several metrics point to decay, while retention remains high enough to tempt incrementalism.
- The evidence supports action but does not prove a final category name.

## Comparable output question

The evaluation does not ask which skill writes the best prose. It asks which workflow most improves this decision:

> What should HelioDesk change about whom it serves, the market frame it uses, and the value it proves during the next 90 days?
