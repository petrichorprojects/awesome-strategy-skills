# Roadmap

## Now: trusted directory

- Publish the outcome-based editorial catalog.
- Feature Resilience Stack with an explicit maintainer disclosure.
- Enforce structured metadata, link checks, and Markdown quality.
- Establish public admission, correction, and removal policies.
- Recruit the first independent reviewers and contributors.

## Next: Petrichor Strategy Skill Index

- Publish canonical evaluation fixtures for market, positioning, product, pricing, and executive decisions.
- Add blinded output review templates and inter-rater agreement guidance.
- Record version-pinned evaluation evidence for reviewed skills.
- Surface input requirements, output artifacts, safety behavior, and failure modes.
- Publish quarterly “State of AI Strategy Skills” findings from the catalog and evaluation set.

## Later: useful infrastructure

- Add a searchable web interface generated from `data/catalog.json`.
- Offer install commands and compatibility matrices where they can be verified.
- Add opt-in update feeds for categories and newly reviewed entries.
- Create “mentioned in Awesome Strategy Skills” assets for included maintainers.
- Develop reproducible evaluation tooling without turning judgment into a vanity leaderboard.

The roadmap is intentionally ordered: trust before scale, evidence before ranking, utility before sponsorship.
